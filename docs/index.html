stamp-maker

LINEスタンプの制作を助けるデスクトップアプリ(macOS)。画像生成はローカルで行います。

最新版: v0.1.0(リリース後に更新)

macOS Apple Silicon (arm64) 最新版をダウンロード

過去のリリース一覧は Releases から確認できます。

主な機能

  • 参考画像から、表情・ポーズ違いのスタンプ画像をローカルで生成(FLUX.2 klein 4B / stable-diffusion.cpp)
  • 文字の合成、LINE の仕様検証、PNG と ZIP の書き出し、申請前チェック
  • 動作環境: macOS(Apple Silicon)。モデル(約8GB)は付属せず、README の手順で用意します
